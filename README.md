# My work
My code is really simple I use a Python script that evaluates math problems entered by a user. I use the eval() function with mathematical operations. If you enter an invalid answer it will say object is non subscriptable which means that you have to try another option and enter a valid number or math problem. My code uses functions sqrt, factorial, log, and trig (sin, cos, tan).

It runs in a loop so that users can do as many problems as they please until they type exit. When they type exit that will cause the code to close.
